# Data — 14 Eye Disease Screener

## Note on raw files

Raw image/audio files are not included in this repository due to size constraints.
The metadata file documents the dataset composition used for model training.

## Reproducing the dataset

See `model/train.py` for the feature extraction pipeline.
Raw files can be obtained from the open-access sources listed in `dataset_metadata.json`.
